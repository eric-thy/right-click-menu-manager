# Security policy

## Reporting

Please report security issues privately by opening a security advisory in this repository rather
than a public issue. Include the affected version, reproduction steps, and the potential impact.

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Scope

The application is a local context-menu manager. It does not run a network service and does not
collect telemetry. Reports about registry operations, privilege boundaries, path handling, and
untrusted Appx manifest parsing are in scope.
